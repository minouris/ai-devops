## Step 2: Create PR Using gh CLI

**Execute gh pr create command:**

```bash
gh pr create \
  --title "Publish AI artifacts: {brief-summary}" \
  --body "$(cat <<'EOF'
{generated-pr-description}
EOF
)"
```

**Title format:**
- "Publish AI artifacts: validator agent, publish skill"
- Keep under 72 characters
- List primary artifacts

**MUST:**
- Use `gh` CLI (authenticated with GitHub)
- Include complete PR description
- Use HEREDOC for body to preserve formatting

**Handle errors:**
- If `gh` not authenticated: Report "GitHub CLI not authenticated. Run: gh auth login"
- If remote not configured: Report "No git remote configured. Add remote first."
- If PR creation fails: Report error and provide manual PR creation instructions

**MUST:**
- Include PR URL (clickable link)
- List published artifacts
- Provide clear next steps
- Note that changes are not in main until PR merged

**MUST NOT:**
- Merge PR automatically
- Push to main directly
- Skip PR creation step

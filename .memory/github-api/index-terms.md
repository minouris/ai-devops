# Terms Index

| Term | Short Description |
|------|-------------------|
| [Base Branch](github-api-terms.md#base-branch) | The target branch in a pull request that will receive merged changes from the head branch |
| [GitHub API](github-api-terms.md#github-api) | The umbrella interface provided by GitHub for programmatic access to repository data and automation |
| [GitHub GraphQL API](github-api-terms.md#github-graphql-api) | GitHub's GraphQL implementation enabling clients to request specific data fields and nested relationships |
| [GitHub REST API](github-api-terms.md#github-rest-api) | GitHub's REST implementation using HTTP methods and endpoint paths for API access |
| [GraphQL API](github-api-terms.md#graphql-api) | A general query language enabling clients to request exactly the data they need |
| [Head Branch](github-api-terms.md#head-branch) | The source branch in a pull request containing the changes being proposed for integration |
| [Pull Request (PR)](github-api-terms.md#pull-request-pr) | A mechanism for proposing changes to a repository, enabling code review and CI/CD automation |
| [Repository Configuration](github-api-terms.md#repository-configuration) | Parameters defining which GitHub repository a skill or operation targets |
| [REST API](github-api-terms.md#rest-api) | An architectural style for web APIs using HTTP methods to manipulate resources |
| [Review Thread](github-api-terms.md#review-thread) | A conversation thread within a pull request containing code review comments |
